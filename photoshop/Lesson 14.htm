Яркостные маски из каналов на примере синей подсветки

Задача: поднять яркость всей картинки, кроме уже ярких синих элементов подсветки. Важный вывод: иногда быстрее и чище сделать маску не через Color Range, а прямо из канала.

Color Range

Выделить синие участки (пипеткой «потыкать» по синему).
Создать Curves — выделение загрузится в маску.
Инвертировать маску, чтобы осветление не проходило на синий.
Нюанс: маска может «проползти» и дать обрезанное влияние (часть изображения перестаёт осветляться слишком рано).

Каналы

Открыть Channels и посмотреть, где контраст между синим и остальным наиболее удобен.
В примере подходит Red channel: синие элементы становятся тёмными.
Загрузить выделение по каналу: Cmd/Ctrl + клик по пиктограмме канала
Вернуться на композитный RGB, создать Curves — выделение загрузится в маску.
Внутри маски (Alt-клик по маске) вызвать деструктивные кривые для маски - Curves: Cmd/Ctrl + M.
Подтянуть точку белого/чёрного (убрать «дырки» в гистограмме маски), сделать маску более полезной.
По этой маске аккуратно поднять яркость.

Яркостная маска для объёма на портрете и «интерактивная маска» через Channel Mixer

Здесь цель — сделать свет на лице менее плоским, «вытянуть блики» и добавить объём.

Вариант: выделить мальчика → маска → Curves

Выделить мальчика:
Select Subject (быстрый старт выделения объекта).
Создать корректирующий слой Curves — выделение загрузится в маску автоматически.
Корректировать кривыми яркость/контраст внутри выделенной области.
При необходимости уточнить маску:
зайти в маску и подрисовать кистью (добавить/убрать зоны влияния), чтобы коррекция не лезла на фон.

Яркостная маска из канала

Оценить, в каком канале рельеф читается лучше (в примере выбиралось между Blue и Green).
Загрузить выделение по выбранному каналу (Cmd/Ctrl + клик по каналу).
Создать Curves и работать по маске.
Если нужно — отредактировать маску (Alt-клик по маске, Curves внутри маски).
Ограничить влияние (например, чтобы не лезло на одежду): дорисовать/вырезать по маске группы.

Проблема «фиксированной» пиксельной маски

Если после создания маски ретушь на изображении меняется (прыщики убрали, детали поменялись), в маске остаётся «старый рельеф», и маску приходится перестраивать заново.

«Интерактивная маска»

Идея: сформировать локализованный контраст через Channel Mixer (Monochrome), положить в Overlay, а затем ограничить влияние через Blend If (Layer Style).

Последовательность

Создать корректирующий слой Channel Mixer.
Включить Monochrome.
Вывести один канал (пример логики):
0 Red, 0 Green, 100 Blue — для синего канала или аналогично для зеленого, если он подходит.
Значение канала - увеличения до 200% и Constant - отрицательное значение) - условный аналог воздействия контрастной кривой на яркостную маску.
Перевести слой в Overlay.
Открыть Layer Style → Blend If (двойной клик по слою) и запретить слою проявляться в тенях:
Current и Underlying Layer расщеплением Alt/Option** в границы значений черного и белого.
Воздействие и интенсивность проявляется либо по маске в нужных местах
И/или прозрачностью слоя

Обтравка волос: почему не «в лоб» и чем заменять

Прямой «вырез волос» часто физически выглядит плохо из-за полупрозрачности, расфокуса и смешивания с фоном. Поэтому во многих кейсах лучше менять фон/свет и использовать режимы наложения, а для сложных переносов — подключать AI.

Волосы сложно обтравливать

Волосы ведут себя как полупрозрачная фактура: тонкие пряди + расфокус → нет чётких границ, через них просвечивает фон.
Полупрозрачная маска в проблемной зоне покажет не «чистые волосы», а смесь волос + цвет фона.
Если исходный свет не предполагает контрового отделения, перенос на противоположный фон (например, на чёрный) выглядит неестественно.

Select Subject и Select and Mask

Select Subject даёт «неплохую, но не идеальную» маску: для цветокоррекции может хватить, для коллажей — часто нет.
В маске можно открыть Select and Mask и использовать кисть refinement:
Кисточка, которая пытается искать волосы и модифицировать маску.
Но итоговый результат будет средним.

Подход «модифицировать фон вместо обтравки волос» (кейс с серым фоном)

Исходный фон серый (тёмно-серый, но всё ещё серый).
Сделать фон более похожим на облачное небо через Curves:
поднять яркость,
слегка сместить оттенок (пример: синий вверх, красный чуть вниз),
По грубой маске кистью ограничить влияние на волосы так, чтобы осветление «проползало на кончики», но не входило в основную массу волос.
Наложить небо отдельной картинкой в Overlay, дополнительно убрать лишнюю синеву фона Hue/Saturation.
Дальше — Dodge & Burn на среднесером слое в Soft Light:
белой/чёрной кистью с небольшой непрозрачностью осветлить/затемнить,
проявлять по грубой маске.

Маска насыщенности + Darken

Маска насыщенности + Darken при замене светлого фона на тёмный помогает перенести тёмные волосы и тени:

Cложные переносы волос

Для переноса на «противоположный» фон (темные волосы со светлого на темный, к примеру) стоит использовать AI.

Маска насыщенности

Смысл: получить ч/б карту, где светлое = более насыщенное, тёмное = менее насыщенное, и на основе этой карты строить маски для точных коррекций.

LUT (условно)

LUT — «особый вид RGB цветокоррекции» и формат хранения коррекции.
Таблица, где «какой цвет → в какой перекрашиваем».

LUT в Photoshop

Файлы LUT копируются в папку Photoshop:
Presets → 3DLUTs.
Photoshop нужно закрыть и перезапустить, чтобы LUT появились в списке.
Применение:
создать корректирующий слой Color Lookup,
выбрать нужный LUT из выпадающего списка.

Получение «заготовки» маски насыщенности

Наложить Color Lookup с техническим LUT → получить ч/б картинку насыщенности.
Сделать «слепок видимого» в новый слой:
Stamp Visible: Windows Ctrl + Alt + Shift + E, macOS Cmd + Option + Shift + E.
Удалить LUT-слой: «он отработал и сделал свою работу».
Сделать заготовку полноконтрастной:
Auto Levels: Windows Shift + Ctrl + L, macOS Shift + Cmd + L.
Подконтрастить маску так, чтобы светлыми остались только зоны, на которые нужна коррекция.

Коррекция кожи по маске насыщенности (логика)

Скопировать заготовку (Ctrl/Cmd + A, Ctrl/Cmd + C).
Создать корректирующий слой Hue/Saturation.
Войти в маску (Alt/Option при клике по маске) и вставить заготовку (Ctrl/Cmd + V).
По маске снизить насыщенность в самых насыщенных участках (губы при необходимости исключить).
Затем сделать второй Hue/Saturation - поднять общую насыщенность уже после того, как «привели кожу к одному знаменателю».
Для стабильной светотени перевести корректирующие слои в режим наложения Color, чтобы не трогать яркостную составляющую.

Маска насыщенности без LUT: HSB/HSL

Если LUT нет, маску насыщенности можно получить нативно. Суть: перевести изображение в HSB или HSL и взять канал, где живёт насыщенность.
Перевести изображение в HSB или HSL - Filter → Other → HSB/HSL.
В этих пространствах каналы распределяются так:
Red — кодирование оттенков,
Blue — яркостная составляющая,
Green — насыщенность.
Выбрать, что «больше нравится под задачу»: HSB или HSL, потому что математика перерасчёта немного отличается.

Комбинирование масок: оттенок + яркость + насыщенность

Сначала исключить из изображения всё, что не относится к нужному оттенку (обесцветить всё, кроме нужных оттенков), а уже потом делать маску насыщенности.
Делать маску оттенков через:
Hue/Saturation,
перевод слоя в Difference,
слепок результата,
выбор наиболее контрастного канала,
Auto Levels.
Делать яркостную маску из композитного канала:
Cmd/Ctrl + клик по RGB (композитному) → «усреднённое выделение по яркости всех трёх».

Как объединять маски

Сначала определять, по какому признаку проще всего отделить нужную зону: оттенок, яркость или насыщенность.
Делать по одному «черновику» маски под каждый признак (маска оттенка / яркостная маска / маска насыщенности).
Дальше объединять маски в зависимости от задачи:
когда нужно сузить влияние — комбинировать маски в затемняющей логике (Darken / Multiply),
когда нужно расширить влияние — комбинировать в осветляющей логике (Lighten / Screen).
После объединения всегда доводить итог:
подконтрастить (Levels/Curves/Auto Levels),
при необходимости инвертировать,
проверить края и «лишнее» вручную кистью по маске.

Кейсы: отделение объектов по насыщенности и по оттенку через Difference

Difference «сравнивает текущий слой и ниже лежащую картинку»:
где разницы нет — чёрный,
где разница есть — показывается величина разницы по каналам.

Отделение по насыщенности (пример: рыжие волосы на почти сером фоне)

Фон почти серый → насыщенность минимальная.
Волосы рыжие → насыщенность выше.
Канал насыщенности (в зависимости от модели) может отделить волосы от фона достаточно хорошо.

Убрать тень под лифчиком

Задача: тень под лифчиком делает впечатление, что лифчик «отстоит от кожи», поэтому тень нужно убрать.

Вариант 1 — через маску насыщенности

Проверить RGB‑каналы: разница между лифчиком и тенью может быть недостаточной.
Проверить маску насыщенности (разные модели) и выбрать ту, где лифчик/тень отделяются лучше.
Доработать затемнителем (в тенях) при необходимости.
Инвертировать маску так, чтобы была выбрана кожа.
По маске штампом «ниже» накопировать кожу, убирая тень.

Вариант 2 — через оттенок и Difference

Создать Hue/Saturation, взять красный оттенок.
Поставить Hue на +180, чтобы увидеть зону влияния, и настроить диапазон так, чтобы кожа (жёлто‑оранжевая) не попадала.
Перевести этот Hue/Saturation в режим Difference.
Слепить результат в новый слой (Stamp Visible) и удалить временный Hue/Saturation.
В каналах найти, где маска лучше читается (в примере — Green channel).
Скопировать канал в слои, сделать Auto Levels.
При необходимости инвертировать (Ctrl/Cmd + I) — получить правильную сторону маски.
По маске штампом «ниже» накопировать кожу, убирая тень.

Экшены

Экшены живут в Actions panel: Window → Actions.
Экшены экспортируются/импортируются только папками (Set):
Save Actions → *.atn,
Load Actions → загрузка *.atn.
Создать экшен - + внизу панели
Во время записи:
не кликать мышкой по слою до задания ему оригинального названия: на выделенном слое Layer → Rename Layer или из выпадающего меню - в правом верхнем углу панели Layers (бутерброд)
лучше перемещаться по слоям клавишами и заранее задавать уникальные имена.
Любое действие внутри экшена можно раскрыть, удалить, менять местами (но перестановка может сломать логику). Не забывайте отключать запись в этот момент, чтобы действие не записалось в экшен.
В Actions у шага (например, Gaussian Blur) можно включить значок диалога (маленький квадратик), чтобы при запуске экшен спрашивал радиус и давал его изменить. А так же отключить действие - галочка слева.
