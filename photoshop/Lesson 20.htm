LUT для пакетной обработки

Идея

Сложные цветокоррекции часто состоят из нескольких корректирующих слоёв, режимов наложения и масок. При пакетной обработке воспроизводить эту «многоступенчатую» схему на десятках кадров неудобно.

Проблема масок при правках «по ходу»

Если маска сделана до ретуши/изменения яркостей, а потом в изображении меняются детали:
дефект (прыщик/пятно) мог попасть внутрь маски, затем быть удалён ретушью, но «след» останется в маске;
после Dod&Burn меняются яркости и цвет в тенях, а маска, сделанная раньше, начинает выглядеть неадекватно.

Решение

Запаковать комплексную цветокоррекцию в LUT, чтобы:
вместо множества слоёв использовать один слой Color Lookup;
получить эффект, который ведёт себя стабильно при последующих изменениях изображения (маски и логика коррекции как бы «внутри LUT»).

HALD

HALD — это изображение-таблица, где каждый пиксель соответствует строке условной «таблицы соответствий цветов» LUT.
В HALD содержатся опорные цвета (градиенты от чёрного до белого, оттенки серого и множество цветовых значений).
Программы конвертации знают исходные (эталонные) цвета HALD и могут сравнить их с изменённой версией, чтобы получить LUT-файл.

Важные правила работы с HALD

HALD нельзя масштабировать и нельзя допускать изменения пикселей компрессией.
Выделение при копировании HALD должно быть без размытия края (feather = 0).
Разрешены корректирующие слои, режимы наложения, сложные маски.
Запрещены ручные правки кистью по маскам и размытие масок.
Причина запретов: одинаковые по цвету пиксели на фотографии и в HALD должны обрабатываться одинаково. Ручная дорисовка/размытие маски делает локальные изменения, и тогда часть цветов на фото будет корректироваться иначе, чем те же цвета в HALD.

Подготовка HALD внутри рабочего документа

HALD открывается отдельным документом, затем копируется и вставляется в рабочий документ «как часть картинки».
Все дальнейшие цветокоррекции выполняются так, чтобы они одинаково проходили и по изображению, и по HALD.
Нужно получить изображение HALD уже с применёнными корректирующими слоями.
Используется команда Copy Merged Shift+Cmd+C (копировать видимое) — чтобы забрать результат «что видно на экране».
В новый документ вставляется изменённый HALD.
Сохранение строго в PNG (JPEG запрещён из-за сжатия и изменения пикселей).

Конвертация PNG HALD → LUT (.cube)

Изменённый HALD PNG загружается в бесплатный онлайн-конвертер https://convert.viktorfejes.com/, который выдаёт LUT-файл .cube.

Важное ограничение

LUT, созданный под конкретную съёмку, не претендует на универсальность: он адекватен для похожего света и похожего skintone.

Коррекция насыщенности

В одном и том же изображении разные участки кожи могут иметь разную насыщенность: где-то «серее», где-то «насыщеннее».

Ход работы (идея)

Свести изображение на один слой (вместе с уже примененными коррекциями/лутом, если нужно).
Перевести изображение из RGB в HSB.
Работать с каналом, отвечающим за насыщенность (Green):
открыть Curves,
поставить «козой» точки по насыщенному участку и по «слишком серому» участку,
поднять насыщенность поставить точку и не отпуская мышки двигать вверх там, где серо,
Вернуть обратно в RGB.
После таких манипуляций картинка может стать темнее.
положить результат в режим наложения Color,
запретить коррекции проявляться в бликах через Blend If (чтобы блики оставались нейтральными и не становились «насыщенными»).
Растаскивание ползунков делает границу влияния мягкой.
После выравнивания насыщенности стоит дополнительно чистить желтизну через Hue/Saturation в режиме Color и ограничивать воздействие по диапазону.
Данную обработку можно сделать с внедренным HALD, чтобы сделать сложные коррекции ввиде лута и применять потом на всю серию похожих изображений.

Типичная пакетная обработка

Подготовка серии в ACR

Серия настраивается одинаково (кадрирование/конвертация), при необходимости экспозиция чуть отличается по кадрам.
Кадры сохраняются из ACR сразу в PSD.
Сразу задаётся уменьшение при сохранении: длинная сторона/высота до 3000 px, профиль sRGB, 8 bit.
Опция Don’t Enlarge используется, чтобы не увеличивать файлы, которые уже меньше заданного размера.

Написание одноразового экшена под конкретную серию

Подход: все PSD имеют одинаковую послойную структуру (один слой Background), поэтому в экшене допустим выбор слоёв мышкой.
В экшен включены действия:
запуск Retouch4me (например, Heal + Dodge&Burn) с группировкой слоёв;
снижение непрозрачности слоя Dodge&Burn (под мужскую ретушь эффект ослабляется);
создание маски кожи через Select People (выбор частей: facial skin, upper body skin, arms и т.п.);
применение подготовленного LUT на кожу через Color Lookup с регулировкой силы эффекта;
замена цвета фона (например, жёлтый фон) через Select Subject → инверсия выделения → Solid Color в режиме Multiply (чтобы тени прокрасились);
дополнительное повышение общей насыщенности, если персонаж стал слишком «вымытым» на новом фоне;
доработка фона (при необходимости): корректирующие слои Curves, общая подстройка оттенка;
работа с одеждой: Select People → выбор одежды → фильтр Dust & Scratches для возврата фактуры и удаления пыли;
контроль насыщенности фона отдельным Hue/Saturation.

Запуск Batch

File → Automate → Batch.
Выбор экшена.
Указание папки с PSD.
Опции подавления диалогов - Suppress...
Режим сохранения: Save and Close.

Доработка после Batch

После пакетного прогона серия открывается по одному файлу и контролируется:
не прошла коррекция на часть волос/краёв;
коррекция залезла на губы/глаза/зубы;
захватился/не захватился кусок фона в маске;
Multiply на фоне «роняет точку белого» (например, на целлофане появляются проблемы в бликах);
где-то требуется ручная ретушь Healing Brush.

Типовые исправления

Добавить/убрать область из маски:
выделить нужное (Select Object / Select Subject / Select People);
на маске залить выделение:
Windows: Alt+Backspace — заливка цветом переднего плана; Ctrl+Backspace — фоновым цветом
macOS: Option+Delete — заливка цветом переднего плана; Command+Delete — фоновым цветом
Инвертировать выделение: Windows: Shift+Ctrl+I / macOS: Shift+Command+I.
Инвертировать маску: Windows: Ctrl+I / macOS: Command+I.
Ограничить Multiply по бликам через Blend If (запрет проявления в ярких участках).

Сценарий «забыли добавить правку на всю серию»

Если все PSD имеют одинаковую послойную структуру, можно:
открыть один файл;
включить запись нового экшена;
добавить корректирующий слой (например, усиление объёма на коже через Channel Mixer/контрастный экшен), настроить непрозрачность;
остановить запись;
Batch прогнать новый экшен по всей папке.

Сценарий «правка нужна только для части кадров»

Чтобы не применять правку ко всем:
создать временную папку;
сложить туда только нужные PSD;
Batch прогнать экшен по этой папке;
вернуть файлы обратно;
временную папку удалить.

Сценарий со Smart Object из ACR

Если требуется повторная манипуляция с проявкой RAW — из ACR все файлы открываются в Photoshop как Smart Object.
File → Close All → подтвердить сохранение (Apply to All) → серия сохраняется как Photoshop-файлы в выбранную папку.
Переименование слоя
Важный нюанс: слой имеет имя файла, а имена разные в каждом PSD.
Слой переименовывается через команду Rename Layer (без клика по имени), чтобы во всех файлах он стал одинаковым (например, Source).
Далее написание временного экшена и Batch.

Прием Liquify через Smart Filters

Делается слепок результата на новом слое (merge visible).
Слой конвертируется в Smart Object.
Liquify применяется как Smart Filter.
Если потом требуется изменить изображение, старый слой с Liquify отключается, создаётся новый слепок, снова Smart Object, и Smart Filters перетаскиваются на новый слой.

Пакетное сохранение

Когда нужно пакетно сохранить большое количество файлов.
В Photoshop есть встроенный скрипт Image Processor.
File → Scripts → Image Processor.
Select Folder - папка с исходными файлами
Куда сохранять:
в ту же локацию (Save in Same Location) или в выбранную папку.
Keep folder structure - сохранение папковой структуры.
Форматы сохранения:
JPEG / PSD / TIFF.
у каждого формата свои настройки (например, качество JPEG; LZW-компрессия в TIFF).
можно включить двойное сохранение (например, и JPEG, и TIFF).
Image Processor создает внутри выбранной папки отдельную папку с названием формата и кладет результаты туда.
Запуск: кнопка Run.
Модифицировать картинку (резкость, выравнивание, ретач и т. д.) нужно до сохранения, отдельными экшенами/обработкой.

Ресайз и резкость

Если резкость нужна только из-за уменьшения

При downscale можно выбирать метод ресэмплинга, ориентированный на резкость (например, bicubic sharper в зависимости от интерфейса/режима изменения размера).

Контроль градиентов

При изменении размера плавные градиенты могут начать «ломаться» (постеризация).
После уменьшения иногда требуется дополнительная легкая обработка, чтобы побороть постеризацию (например, небольшой blur экшеном по фону — по ситуации).

Практический сценарий «не шарпить исходник»

Можно уменьшить и сохранить JPEG с максимальным качеством.
Затем запустить экшен шарпа уже по JPEG (однократное пересохранение JPEG с качеством 12 сильной деградации обычно не дает).
В любом случае нужно контролировать, не поползли ли градиенты после downscale и после пересохранения.
