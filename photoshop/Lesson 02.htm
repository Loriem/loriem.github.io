Настройка панели Tools (Toolbar)

Настройка панели Tools: очистка от лишних инструментов

Панель Tools (левая вертикальная панель) можно настраивать.
Путь: Edit → Toolbar.
Логика настройки: переносить ненужные инструменты из левой колонки вправую, чтобы убрать «маркетинговую ерунду», старые/неиспользуемые инструменты.
Примеры того, что убиралось/оставлялось на занятии:
Убиралось: Artboard Tools, Selection Brush Tool, Magnetic Lasso Tool, Magic Wand Tool (оставлялись инструменты выделения объекта/быстрого выделения), часть инструментов кадрирования/рамок, Red Eye Tool, часть «лечащих» (Spot Healing), часть кистей (карандаш, Color Replacement), History Brush Tool, часть «шарпящих» и «маркетинговых» кистей.
Оставлялось: базовые выделения, Crop Tool, Eyedropper, Brush Tool, Mixer Brush, Clone Stamp, обычный Eraser, Gradient и Paint Bucket, Blur/Smudge и др.
В процессе настройки может появиться группа «спрятанных» инструментов с отдельной настройкой горячих клавиш:
опция Disable Shortcuts для спрятанных инструментов.

Move Tool: когда включать и зачем выключать Auto-Select

Move Tool (перемещение) напрямую почти не включается.
Единственный раз: зайти в инструмент и снять галку Auto-Select, потому что она мешает.
Перемещение объектов чаще делается так:
любой инструмент (например, выделение/кисть),
зажать Ctrl (Windows) / Command (Mac),
временно получаем Move Tool и двигаем объект.

Zoom и навигация: как приближать/отдалять без «лупы»

Лупа (Zoom Tool) вызывается клавишей Z.
Отключалем функцию Scrubby Zoom, чтобы лупа работала через растягивание прямоугольника (пунктирного выделения) для приближения нужной области.
Основные способы навигации:
Ctrl + / Ctrl − (Windows) или Command + / Command − (Mac) — приближение/отдаление шагами.
Space (пробел) — временно включить Hand Tool и перемещаться по изображению.
Navigator — панель для навигации и масштаба.
Ctrl/Command + 0 — вписать изображение в экран.
Ctrl/Command + 1 — масштаб 100% (пиксель в пиксель).
Масштаб отображается в левом нижнем углу.

Инструменты выделения: Marquee и Lasso

Marquee Tool: базовое выделение

Marquee Tool вызывается клавишей M.
Важная настройка: Feather = 0 (границу выделения не размывать).
Внутри группы Marquee есть несколько инструментов (зажать мышь на инструменте и подержать) :
Rectangular прямоугольное выделение;
Elliptical эллиптическое выделение;
Single Row/Single Column выделение однопиксельного ряда (горизонтального/вертикального) — пригодится, если после операций появляется однопиксельная рамка по краю.
Переключение инструментов внутри одной группы:
Shift + буква (например, Shift + M) — по кругу переключает инструменты группы.
По умолчанию выделение растягивается из угла, при зажатом Alt - из центра. При зажатом Shift - квадратное/круглое с равными пропорциями (ШхВ).
Снятие выделения:
клик по выделению (когда курсор превращается в стрелку с квадратиком) или вне его,
или Ctrl/Command + D (Deselect).

Принципы добавления/вычитания из выделения

На панели Marquee есть 4 режима (создать/добавить/вычесть/пересечение), но на занятии акцент — делать это через клавиши:
Shift при имеющемся выделении — добавление к текущему выделению;
Alt (Windows) / Option (Mac) при имеющемся выделении — вычитание из выделения.

Lasso Tool: лассо для «свободных» выделений

Lasso Tool вызывается клавишей L.
обычное лассо;
Polygonal Lasso (полигональное).
Anti-alias - более сглаженное выделение, «без зубчиков»
Переключение внутри группы: Shift + L.
Полигональное лассо:
формирует выделение по кликам;
удобно для ровных/угловатых контуров.
Backspace — удаление последней поставленной точки.
Дополнение/вычитание из выделения работает так же (Shift / Alt-Option).

Пипетка, кисть, ластик

Пипетка (Eyedropper)

Основная функция — взять цвет с изображения в активный цвет (Foreground).
Alt активация пипетки на инструменте Brush или Gradient
Sample Size - размер области взятия цвета, Point Sample - область в один пиксель, во всех остальных случаях - усредненное значение радиуса.

Кисть (Brush Tool)

Панель настроек Brush Settings
Brush Tool используется постоянно, поэтому важно понимать настройки:
Size (размер); (горячие клавиши [ ])
Hardness (жесткость);
Spacing (шаг кисти — влияет на «пунктирность» мазка);
Opacity (непрозрачность); можно задавать цифрами - нажатие одной - десяток, 1- 10%, 0 - 100%; быстрое последовательное нажатие двух цифр - десяток и единица.
Flow (плотность подачи/«поток»).
Отличие Opacity и Flow на практике:
Opacity ограничивает максимальную непрозрачность мазка;
Flow влияет на то, как быстро «набирается» плотность при рисовании.
Прямая линия кистью:
ставится первая точка,
затем Shift и клик в другую точку — получается ровный штрих.

Сброс цветов и переключение Foreground/Background

D — сбросить цвета на черный/белый (Default).
X — поменять местами Foreground и Background.

Ластик (Eraser Tool)

Инструмент Eraser Tool (ластик) вызывается клавишей E.
Логика работы такая же, как у кисти: у ластика есть Size, Hardness, Opacity и другие параметры, поэтому его можно настроить «мягким» или «жестким».
Ластик удаляет пиксели на слое: на обычном слое появляется прозрачность, а на фоне (Background) стирание идет «в цвет фона».
Инструмент, который лучше применять аккуратно: если нужно стирать — удобнее работать на копии слоя или заранее продумывать способ, чтобы можно было откатиться.

Инструменты «смягчения/размазывания» и осветления/затемнения

Blur/Smudge

Blur используется, когда нужно слегка смягчить переходы или локально убрать «лишнюю резкость», но при сильном воздействии быстро превращает участок в «мыло».
Smudge «тянет» пиксели и смешивает их между собой: удобно для небольших подправок, но при чрезмерном применении дает заметные потеки и грязь.
Важные параметры у кисточных инструментов сохраняются по логике кисти (размер, жесткость, spacing и т.д.).

Dodge и Burn

Инструменты работают как кисть: можно рисовать, можно делать ровные отрезки через Shift по точкам.
Ключевая опция: Protect Tones.
без Protect Tones осветление стремится «выбелить», затемнение — «вычернить»;
с Protect Tones осветление/затемнение пытается сохранять воспринимаемый цвет (оттенок/насыщенность), но цвет все равно «едет» по каналам.
Опция Range:
Shadows — работа по теням;
Midtones — работа по средним тонам;
Highlights — работа по светам.
Смысл Range: указать, в какой части тонового диапазона инструмент должен работать сильнее.

Заливка и градиент

Paint Bucket (заливка)

Инструмент заливки.
Логика: выделить область и залить выбранным цветом.
Горячая клавиша для заливки выделенной области цветом:
Alt + Backspace — заливка Foreground (активным цветом).
Если выделения нет — зальется весь слой.

Gradient Tool (градиент)

Градиент применяется либо внутри выделения, либо по всему слою.
Настройки:
выбор градиента (в т.ч. пресеты);
форма: линейный, радиальный, угловой/циркулярный, отраженный, «звездочка».
Dither — включить, чтобы добавлялся небольшой шум и меньше проявлялась «лестница» (постеризация).
Основной сценарий использования на курсе: маски (черно‑белый градиент).

Ретушь: Clone Stamp, Healing, Patch и Remove Tool

Clone Stamp Tool (штамп)

Рабочая схема:
взять источник: Alt (Option) + клик по донорской области;
рисовать по целевой области.
Важные настройки:
Aligned (привязка источника): при включении источник «едет» вместе с кистью, при выключении — каждый мазок начинается из одной и той же точки.
Opacity и Flow работают так же, как в кисти.
Для аккуратной ретуши удобнее работать с графическим планшетом, чем с мышью.

Healing Brush Tool/ «Лечащая кисть»

Копирует текстуру, смешивая ее с окружающим контекстом по цвету и тону.
Используется там, где штамп дает заметные отличия по цвету и тону.
Diffusion - меньшее значение дает меньше артефактов вокруг штриха в зоне контрастных переходов.

Patch Tool (заплатка)

Используется для замены одной области другой с учетом контекста – аналог лечащей кисти но для выделенной области.
Применим для более крупных дефектов.

Remove Tool

Нейросетевой инструмент удаления.
Рабочий принцип:
обвести область (например, лассо) и нажать Remove;
или работать кистью
Find distractions - Wires and cables - найти и удалить провода и кабели, People - предварительно находит и выделяет, а по нажатию галочки - удаляет. Лучше удалять небольшими кусками, чтобы не терять детализацию.
Remove часто срабатывает лучше, чем старые автоматические алгоритмы.

Кадрирование

Crop Tool

Crop Tool используется для кадрирования.
Delete Cropped Pixels — удаляет оставшееся за зоной кадрирования, лучше отключить.

Доливка пространства при кадрировании

В Crop Tool есть настройки «Fill»:
Transparent — ничего не дорисовывается.
Content-Aware Fill — старый алгоритм, без нейросетей: пытается заполнить из существующих фрагментов.
Generative Expand — генеративная дорисовка.

Content-Aware Fill (старый алгоритм)

Может работать неплохо на простых фонах (студийный фон), хуже — на сложном содержимом.
Content-Aware Fill можно использовать не только при кадрировании:
выделить область;
нажать Shift + Backspace и выбрать Content-Aware.

Generative Expand: важный нюанс по разрешению

Generative Expand делает результат на отдельном слое и дает несколько вариантов.
Важный нюанс: при работе с high-res генерация может быть сделана в меньшем «родном» разрешении и затем растянута, что приведет к визуально плохому по детализации результату.
Для лучшей детализации:
генерировать маленькими кусочками (маленькое выделение → Generate Fill).
чем больше деталей и чем больше область, тем выше риск потери детализации.

Вариант за пределами Photoshop: downscale/upscale

сохранить дубль маленьким (например, около 1000×1000);
сделать upscale сторонним сервисом;
вернуть обратно и потом закрыть маской персонажа.

Generative Fill: модели, кредиты и сценарий выбора

Generative Fill и модель

Generative Fill вызывается через контекстную панель (Contextual Task Bar): выделить область → Generate.
Можно писать запрос (понимает русский), а можно генерировать без текста для Firefly моделей.
Модель — это конкретный ИИ, который генерирует результат.

Google Gemini (Nano Banana Pro)

модель часто сильнее по качеству, но встроена в Photoshop «криво»;
для Nano Banana / Nano Banana Pro нужно обязательно задавать промпт, иначе Generate недоступен;
на сложных выделениях возможна некорректная подстановка результата и может потребоваться ручная подгонка.

Кредиты (Credits)

Кредиты — виртуальные «монетки» в аккаунте Adobe.
Логика подписок:
в разных планах разное количество кредитов в месяц;
кредиты обновляются ежемесячно и не накапливаются.
значок () - по наведению видно, сколько кредитов будет списано.

Практический сценарий выбора модели

Сначала пробовать Firefly (дешевле и быстрее проверить).
Если Firefly не справился за 1–2 генерации:
переключаться на Nano Banana / Nano Banana Pro и давать более точный промпт.
У Firefly одна генерация дает 3 варианта, у Nano Banana Pro - 1.
