Геометрические трансформации

Базовая логика трансформаций

Трансформация применяется либо ко всему слою, либо к выделенной области.
Если выделение активно, трансформируется рамка выделения.
Если выделения нет, трансформируется «совокупная область непрозрачных пикселей» слоя.

Free Transform: вызов и базовые действия

Трансформация вызывается клавиатурным сокращением Ctrl + T (Windows) / Command + T (Mac).
Рамку трансформации можно:
вращать,
менять ширину и высоту,
масштабировать за угол.
Отмена применения — Esc.

Важные клавиши-модификаторы при трансформации

Shift:
при включенной настройке Use Legacy Free Transform сохраняет соотношение сторон (квадрат остаётся квадратом);
фиксирует поворот «шагами» по 15 градусов.
Alt (Option):
масштабирование происходит из центра трансформируемой области.
Alt + клик внутри/снаружи области трансформации:
смещение точки, вокруг которой масштабирование «тянется из центра».

Панель Options при активной трансформации

Можно вводить значения ширины/высоты в процентах.
Можно «связать» ширину и высоту через значок цепочки.
Единицы измерения можно переключать (например, проценты ↔ пиксели).
Угол поворота можно вводить числом (операция применится после Enter).
Интерполяция:
рекомендуется не усложнять и оставлять Bicubic.
Automatic выбирает более «умный» вариант (например, может чуть подрезчать при уменьшении).

Контекстное меню Free Transform: виды трансформации

При правом клике по области трансформации доступны варианты:
Scale — только масштабирование.
Rotate — только поворот.
Skew — «параллелограммирование», обычно тянут вдоль сторон.
Perspective — принято тянуть за углы.
Distort — без ограничений можно тянуть куда угодно.
Rotate 180 / 90 CW / 90 CCW — повороты на фиксированные углы: 180, 90 по часовой, 90 против часовой.
Flip Horizontal / Flip Vertical — зеркалирование по горизонтали/вертикали.
Warp — изгибание.

Warp: принцип, сетка и Split Warp

Warp «гнёт» область по сетке.
Количество секторов сетки можно менять:
чаще используется дефолтная 3×3,
большие сетки дают много точек и легко «утонуть» в управлении.
Есть пресеты форм (например, «арка») и параметр силы формы.
Split Warp:
Split Warp Vertically — дробит сетку по вертикали в месте клика.
Split Warp Horizontally — дробит по горизонтали.
Split Warp Crosswise — дробит и вертикально, и горизонтально.

Практическая логика выбора области для Warp

Выбор области важен из‑за стыковки с остальной картинкой.
Чтобы «не порвать» контур, интересующую область удобно загонять в крайний сектор сетки, чтобы остальные границы «стояли на месте».
Альтернатива: выбирать область так, чтобы интересующая часть попадала в центр и рамка вокруг двигалась минимально.

Практика: выравнивание картины под точные пропорции

Кейс: картина сфотографирована с небольшим наклоном и выглядит как трапеция.
Последовательность:
Обрезкой задать соотношение сторон (пример: 24×18).
Создать новый слой, залить цветом прямоугольник нужных пропорций.
Пропорционально уменьшить и поставить гайды по прямоугольнику (вытягиваются при клике и удерживании левой кнопки мышки по линейке).
Удалить прямоугольник (он нужен только для гайдов).
Вызвать трансформацию слоя с картиной.
Выбрать Distort.
Потянуть углы картины так, чтобы они попали в гайды «с маленьким зазором».
Растянуть выделение по гайдам и сделать Image → Crop.
При необходимости повернуть весь документ через Image → Image Rotation.

Puppet Warp

Puppet Warp применяется к вырезанному объекту на отдельном слое.
Последовательность:
Выделить объект.
Скопировать на отдельный слой (Ctrl/Cmd + J).
Убрать объект с фона (через Remove или через Content-Aware Fill).
На слое с объектом: Edit → Puppet Warp.
Поставить точки‑фиксаторы по «суставам» и важным зонам, которые не должны двигаться.
Тянуть нужную точку для деформации.
Alt на точке — поворот вокруг точки.
Инструмент может быть «не самым стабильным» и требовать дополнительных фиксаций.
Сильные искажения на «сюжетно значимой части» (пример: лицо) можно исправлять так:
сделать копию исходной части (лицо),
повернуть обычной трансформацией,
снизить непрозрачность, совместить,
накрыть чёрной маской и белой кистью проявить «не деформированное» лицо.
Так сохраняется наклон/изгиб (например, шеи) от Puppet Warp и «чистая» статичная часть от обычной трансформы.

Дополнение по увеличению объектов и детализации

При сильном увеличении «детали из ниоткуда не появятся».
Варианты:
небольшое увеличение (примерно 1.5×) — обычная трансформация + маска;
большое увеличение — искусственный интеллект:
уточнение: генеративные инструменты имеют ограничение по разрешению области генерации (порядка ~2000 px), большие области могут «растягиваться».

Размытие, резкость и Liquify

Какие фильтры реально используются

Группы, которые нужны:
Blur (чуть‑чуть).
Noise (чуть‑чуть).
Other (чуть‑чуть).
Sharpen (чуть‑чуть).

Blur: Gaussian Blur

Размытие.
Один ползунок — Radius - сила размытия
Фильтр влияет на весь слой, либо на выделение.
Критически важное правило:
Снижение непрозрачности размытого слоя не означает «размыть на меньшее количество пикселов».
Если нужен меньший blur — возвращение к неразмытому состоянию и новый blur с меньшим радиусом.

Blur: Motion Blur

Размытие с направлением (как съемка с проводкой)
Имеет вектор размытия (имитация движения/проводки).

Blur Gallery: основные типы

Iris Blur: внутри ромбиков резко, снаружи — нерезкость; можно делать круг (Shift) и разносить границы перехода (Alt).
Tilt-Shift: линейная зона резкости; между линиями — переход, за пунктиром — полная нерезкость.
Path Blur: как Motion Blur, но по заданной траектории.
Field Blur: несколько точек с разным радиусом, размытие плавно «перетекает» между зонами.
Spin Blur: закручивает картинку вокруг области.
Замечание по практике:
После появления ИИ подобные сложные блюры часто проще заменить генерацией «по промту» (пример: статичная машина → эффект проводки + закрученные колёса).

Резкость: базовый принцип

Если промах по фокусу — спасает только искусственный интеллект.
Если фокус в целом норм, но хочется «чуть более звенящую» картинку — применяется повышение резкости.

Unsharp Mask: основной рабочий фильтр резкости

Используется Unsharp Mask.
Три параметра:
Amount — сила.
Radius — «размер деталей», по которым образуются ореолы.
Threshold — отсечка, чтобы меньше цеплять шум.
Резкость — это образование контрастных ореолов вокруг мелких деталей и контуров.

Коридор радиусов резкости

Типичный рабочий диапазон радиуса: 0.5–2 px.
Значения около 3 px — «на грани расфокуса»; если нужно так много, это похоже на попытку лечить резкостью промах по фокусу.

Усиление резкости в два этапа

Вариант: сначала резкость с большим радиусом (более крупные детали), затем дубль и резкость с меньшим радиусом (более мелкие детали).
Результат часто проявляется по маске только там, где нужно (например, лицо), и может дополнительно ослабляться на областях, где резкость поднялась слишком сильно.

High Pass и контрастные режимы

High Pass — «гауссовое размытие, вывернутое наизнанку».
Даёт те же ореолы, которые потом усиливаются контрастным режимом наложения.
Использование:
High Pass + Overlay,
либо Linear Light с понижением непрозрачности.
Замечание: это по сути тот же принцип, что и Unsharp Mask.

Noise: Dust & Scratches

Убирает пыль, царапины, мелкие контрастные волоски, что-то мелкое и контрастное к фону.
Настройки:
Radius — размер удаляемых элементов.
Threshold — возвращает фактуру (чем выше, тем больше фактуры возвращается).
Практика:
корректировать на дубле,
переводить слой в Darken (если убирается светлое на тёмном) или Lighten (если убирается тёмное на светлом),
проявлять эффект по маске только там, где нужно.

Noise: Add Noise

Используется для добавления шума.
Важная галка: Monochromatic (шум нужен чёрно‑белый).
Режим распределения: Uniform / Gaussian (рисунок шума).

Noise: Median

«Медиан — это тот же самый гаусс, но с попыткой сохранить чёткие контуры».
Применение: частотное разложение.

Liquify

Liquify — «фильтр кисточного формата» для геометрических изменений.
Основная логика: направление движение кисти определяет направление трансформации, так всё и изменится.
Параметры кисти:
Size — размер.
Density — похоже на жёсткость: при большой плотности двигается зона по краю окружности, при меньшей — сильнее в центре.
Pressure — похоже на непрозрачность: меньше — слабее эффект, больше — сильнее.
Восстановление:
Reconstruct Tool — «восстановить» изменения.
Ползунок Reconstruct — откатывает сетку изменений на заданный процент.
Face-Aware:
Отдельные настройки лица (глаза, нос, улыбка, губы, челюсть, лоб).
Предупреждение: «улыбка в ликвифае» выглядит плохо; если нужна улыбка — лучше просить ИИ.
Технические опции:
Pin Edges — не даёт «выползать» границам кадра при деформации.
Freeze Mask — замораживает области, которые не должны двигаться; затем можно стереть инструментом Thaw Mask Tool.
Freeze Mask
Thaw Mask Tool
Show Mesh — показывает сетку.
Save Mesh / Load Mesh — сохранение сетки в файл .msh и применение к другому кадру.
Show Backdrop — показывает нижележащие слои полупрозрачно для сравнения с оригиналом.

Smart Object

Smart Object: базовая идея

Smart Object создаётся через Convert to Smart Object.
Смарт‑объект — это «файл внутри файла».
После конвертации можно уменьшать/увеличивать и «не портить» качество при геометрических трансформациях.

Редактирование смарт‑объекта

Смарт‑объект открывается двойным кликом в отдельном окне.
Внутри можно делать изменения, добавлять слои.
Сохранение внутри смарт‑объекта — Ctrl/Cmd + S.
После сохранения и закрытия смарт‑объект обновляется в основном документе.

Smart Filters

Фильтры, применённые к смарт‑объекту, становятся «смарт‑фильтрами» (недеструктивные коррекции).
Можно:
отключать «глазиком»,
дважды кликать по названию фильтра и менять параметры,
удалять фильтр перетаскиванием в корзину,
менять порядок фильтров.
Коррекции могут «крепиться» к смарт‑объекту как к недеструктивной структуре.

Цена смарт‑объектов

Смарт‑объекты и смарт‑фильтры «утяжеляют файл» и нагружают компьютер.
Плюс: можно «в любой момент недеструктивно откатиться к любой из стадий обработки».

Когда смарт‑объект больше не нужен

Если обработка финализирована, смарт‑объект можно превратить в обычный слой:
Rasterize Layer.
После растрирования теряются свойства смарт‑объекта и смарт‑фильтров.

Дубликаты смарт‑объектов: зависимые и независимые

Если дублировать смарт‑объект обычным дубликатом слоя (Ctrl/Cmd + J) изменения внутри одного смарт‑объекта «переползут» в другой.
Если нужна независимая копия - команда New Smart Object via Copy, тогда два смарт‑объекта «отвязаны друг от друга».

Ограничение смарт‑объекта как слоя

Смарт‑объект «не является пиксельным слоем».
По нему нельзя напрямую рисовать кистью/штампом.
Но можно зайти внутрь смарт‑объекта и рисовать внутри.

Практика: чистка предметки

Кейс: флакон с большими «бесфактурными градиентами».
Последовательность действий:
Удаление лишнего элемента:
выделение (Lasso) + Remove.
Осветление флакона:
выделить флакон,
создать корректирующий слой Curves по текущему выделению,
сделать флакон чуть ярче.
Затемнение фона:
загрузить выделение по маске флакона,
инвертировать выделение (Shift + Ctrl/Cmd + I),
создать корректирующий слой для фона, сделать фон темнее.
Удаление логотипа:
грубо выделить логотип,
скопировать на запасной слой,
удалить логотип через Remove.
Выделение плоскости флакона:
Select Object,
Shift‑добавления/Alt‑вычитания из выделения,
добивка Lasso (сверхточность не нужна).
Копирование «как вижу на экране»:
создать новый слой,
Copy Merged (Shift + Ctrl/Cmd + C) — копируется выделенная область со всеми видимыми коррекциями,
вставить на новый слой.
Перевод в 16 bit перед сильным размытием:
цель: не допустить «лесенки» и постеризации.
Сильный Gaussian Blur большим радиусом до ровного градиента.
Уплотнение краёв:
дублировать размытый слой и слить с нижним,
повторить, чтобы полупрозрачные края наслаивались.
Клиппинг:
размытый слой «прикрепить клиппинг‑маской» к чёткой копии поверхности.
Добавление шума:
Noise → Add Noise,
подобрать значение (пример: около 8),
слить слои.
Возврат в 8 bit после добавления шума.
Маска и мягкая кисть:
белая маска,
мягкой кистью пройтись по краям, где нужно восстановить контур/тени.
Возврат логотипа и «вживление»
Логотип поднимается наверх.
Для вживления используется режим наложения Lighten (логика: под логотипом более светлый фон; буквы логотипа светлее размытой поверхности).

Практика: выравнивание фона

Фон копируется «как вижу» на отдельный слой.
Перевод в 16 bit.
Сильный Gaussian Blur до ровного фона.
Клиппинг к чётко обтравленному фо ну.
Небольшой Add Noise.
Возврат в 8 bit.
Замечание:
Без достаточного зашумления при сохранении в JPEG может «поползти пастеризация».

Практика: трансформации на теле с маской

Лёгкий пример:
Выделить область (Lasso) и дублировать на отдельный слой.
Накрыть слой маской, чтобы нужная часть (например, одежда) не деформировалась.
Отвязать слой от маски (чтобы маска не деформировалась).
Вызвать трансформацию, сделать деформацию.
Чёрной мягкой кистью по маске убрать косяки.
Сложнее (Liquify + маски):
Дубль → Liquify.
Большой кистью подтянуть форму.
Reconstruct Tool для отката нежелательных сдвигов.
Select Object по нужным зонам и «чёрная маска по выделению» с Alt.
Мягкой белой кистью долечить косяки по маске - проявить нужные зоны.

Практика: обработка студийной фотографии

Сначала привести изображение к 4:5, не обрезая сверху и снизу, а «отдалив по краям».
Так как фон студийный и «ничего в себе не несущий», границы фона можно растянуть трансформацией.
Затем:
сделать дубль,
Ctrl + A,
Ctrl/Cmd + J (оставить только содержимое в пределах кадра),
нижний слой удалить.
использовать Remove для удаления выделения

Важное про штамп/лечащую кисть «по чистому слою»

Для Clone Stamp и Healing Brush используется режим семплинга Current & Below.
Это позволяет:
работать по пустому (прозрачному) слою,
брать донорскую область со всей нижележащей видимой картинки.
Content-Aware Fill / Content-Aware (через Fill) работает по слою с пикселями, а не по пустому.

Генерация складок, чтобы «убрать объём живота»

Задача: подобрать складки так, чтобы визуально живот читался меньше.
Принцип: объём читается из-за «светлое вверху, тёмное внизу», поэтому можно нагенерировать другие складки.
Используются генеративные инструменты (упоминание: Firefly / «нана-банана»).

Коррекция фигуры

Слить всё в новый слой: Ctrl + Alt + Shift + E (Windows) / Cmd + Option + Shift + E (Mac).
Конвертировать в Smart Object «на всякий случай».
Liquify:
работать большими кистями, чтобы «контур волной не поехал».
временно маскировать ногу/область, чтобы не двигалась.

Выравнивание фона

Выделить объект → инвертировать → сделать слой с дыркой (Ctrl/Cmd + J).
Отрезать тень (если её не надо размывать).
Перевод в 16 bit.
Дубль слоя с дыркой → клиппинг маск → сильный Gaussian Blur.
если шум добавлять на слой с полупрозрачными краями, шум «не проходит» равномерно.
сначала слить слой с размытием (получить жёсткий контур),
затем Add Noise уже по слитому.
Если радиус размытия оказался маленьким — откатиться и увеличить (пример: «район 500»), можно дублировать в клиппинг и снова слить.
Перевести картинку обратно в 8 bit

Цветокоррекция элементов фона

Маска на слой: чёрным градиентом слегка замаскировать резкую границу.
Коррекция Curves в клиппинге к слою - поднять яркость так, чтобы зоны «слились».
Если оттенок размытого фона отличается от оригинала - применяем цветокоррекцию.
Замаскировать верх маски, чтобы коррекция работала только в нижней части.
