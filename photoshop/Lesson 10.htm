Режимы наложения: базовая идея и группы

Что такое режим наложения

Режим наложения задаёт, как показывать пиксели слоя и по какой формуле смешивать их с нижележащим изображением (по принципу смешивания красок с тем, что лежит ниже).

Важное свойство

Большинство режимов наложения (кроме группы Hue/Saturation/Color/Luminosity) работают по-канально: отдельно с чёрно‑белой картинкой в каждом канале.

Основные группы

Режимы наложения делятся на группы (в списке Photoshop они разделены черточками):
Затемняющие — затемняют изображение.
Осветляющие — осветляют изображение.
Контрастные — одновременно могут затемнять и осветлять.
Технические — используются для «болванок» под маски, математических задач, внутренней техники.
HSB/«яркосноцветная» группа — Hue / Saturation / Color / Luminosity: работают не по RGB‑каналам, а по другой логике.

Затемняющие и осветляющие: «братья» и нейтральные цвета

Пары «затемнение ↔ осветление»

В затемняющей группе каждый режим имеет «брата‑близнеца» в осветляющей группе:
Darken ↔ Lighten
Multiply ↔ Screen
Color Burn ↔ Color Dodge
Linear Burn ↔ Linear Dodge
Они построены по одному принципу, но действуют в противоположную сторону.

Нейтральные (невидимые) цвета

У каждой из групп есть «нейтральный» цвет, который не оказывает эффекта:
Для затемняющей группы нейтральный цвет — белый (255,255,255). Белый «не умеет затемнять».
Для осветляющей группы нейтральный цвет — чёрный (0,0,0). Чёрный «не умеет осветлять».
Любое отклонение от нейтрального на 1 тоновый уровень уже начинает работать (например, 254 вместо 255).

Darken и Lighten

Lighten

Lighten показывает те пиксели, которые светлее при сравнении пикселей текущего слоя и нижележащего изображения.

Darken

Darken показывает те пиксели, которые темнее при сравнении пикселей текущего слоя и нижележащего изображения.

Предназначение

Это режимы для быстрых «вклеек» без обтравки, когда совпало соотношение «объект светлее/темнее фона».

Multiply и Screen

Multiply (затемнение)

Multiply затемняет по логике падения точки белого и даёт падение контраста по всему тоновому диапазону. Влияние сильнее в светах и уменьшается к теням.

Screen (осветление)

Screen осветляет по логике подъёма точки чёрного и также даёт падение контраста по всему тоновому диапазону. Влияние сильнее в тенях и уменьшается к светам.

«Невидимые» цвета

В Screen чёрный не виден.
В Multiply белый не виден.

Color Burn / Color Dodge и Linear Burn / Linear Dodge

Color Burn

Color Burn — двигает точку черного вправо, агрессивное затемнение, умеет уводить тени в отсечку, при этом повышает контраст на оставшемся диапазоне.

Color Dodge

Color Dodge — двигает точку белого влево, агрессивное осветление, умеет уводить света в отсечку.

Linear Burn / Linear Dodge

Linear Dodge — двигает и точку белого, и точку черного, организуя параллельный перенос кривой выше первоначального положения.
Linear Burn — двигает и точку белого, и точку черного, организуя параллельный перенос кривой ниже первоначального положения.
Linear Burn и Linear Dodge могут приводить к отсечке:
Linear Dodge — в светах,
Linear Burn — в тенях.

Контрастные режимы: нейтральный 50% серый

Нейтральный цвет контрастной группы

Для всей контрастной группы нейтральный (невидимый) цвет — средний серый 128.
В Photoshop можно создавать слой сразу в нужном режиме (например, Hard Light) и заливать его нейтральным цветом (опция Fill with neutral color): такой слой визуально «ничего не делает», пока на нём не появятся пиксели светлее/темнее 128.

Hard Light

Hard Light — это Multiply + Screen в одном режиме:
Всё светлее среднего серого осветляет по алгоритму Screen.
Всё темнее среднего серого затемняет по алгоритму Multiply.
Осветление и затемнение происходят с падением контраста по всему диапазону.

Vivid Light

Vivid Light — это Color Dodge + Color Burn вокруг среднего серого. Режим может выжигать света и тени, повышая контраст.

Linear Light

Linear Light — это Linear Dodge + Linear Burn вокруг среднего серого. Тоже может уводить в отсечку, но действует по «линейной» логике.

Overlay

Overlay — контрастный режим, где осветление/затемнение происходит «дугообразной» логикой без движения точки чёрного и точки белого. Максимальное влияние приходится на среднюю часть тонового диапазона и уменьшается к краям.

Осветление в Overlay

Soft Light

Soft Light — «младший брат» Overlay: эффект похожий, но мягче и с акцентом влияния в левой части диапазона (в тенях/3⁄4 тонах). Точка чёрного и точка белого не двигаются.

Как режимы наложения работают по каналам

Ключевая идея

«Цвет» — это производная: под ним скрываются три чёрно‑белые картинки (R, G, B). При наложении режим преобразует каждый канал отдельно.

Практический вывод

Один и тот же цветной штрих в разных режимах равен трем отдельным изменениям кривых в каждом канале — и итоговый цвет получается из суммы этих трёх независимых преобразований.

Hue / Saturation / Color / Luminosity (HSB‑логика)

Эта группа берёт из слоя не RGB‑каналы, а отдельные составляющие «цвета»:
Color берёт с текущего слоя только хроматику (цвет) (оттенок + насыщенность), а яркость/светотень — с нижележащей картинки.
Luminosity берёт с текущего слоя только яркостную составляющую (яркость), а цвет (оттенок + насыщенность) — снизу.
Hue берёт с текущего слоя только оттенок, насыщенность и яркость — снизу.
Saturation берёт с текущего слоя только насыщенность, оттенок и яркость — снизу.

Типичный смысл

Эти режимы используют, когда от коррекции нужно «протащить» только яркость или только цвет, чтобы не происходили нежелательные сдвиги.

Lighten vs Lighter Color и Darken vs Darker Color

В чём разница

Lighten/Darken работают по‑канально (RGB): сравнивают чёрно‑белые картинки каждого канала, из-за чего при цветных накладках может получаться «странный» результат.
Lighter Color/Darker Color определяют, какой пиксель светлее/темнее не по RGB‑каналам, а по параметру Brightness (HSB‑логика), и выводят целиком пиксель «как ожидается».

4 глобальных случая применения режимов наложения

1) Перевести коррекцию в нужный нам формат

Если коррекция даёт правильную яркость, но «ползёт» цвет — коррекцию переводят, например, в Luminosity.

2) Рисование кистью для той или иной задачи

Пример логики: плоскую красноту без светотени можно «прибрать» бежевым в режиме Color.

3) Комбинирование масок

Сложение/вычитание сложных масок через режимы наложения.

4) Вживление одной картинки в другую

Наложение одного изображения на другое для композита (самый наглядный сценарий).

Практика: быстрые вклейки без обтравки (Lighten/Darken)

Волосы без сложной обтравки

Если волосы светлее, чем фон:
слой с волосами переводится в Lighten,
создаётся чёрная маска,
мягкой кистью проявляются только нужные области.
Это позволяет сложить волосы «дёшево и быстро», без долгой сложной маски.

Объект на фоне через Darken

Если объект темнее фона (пример с «вороной на газоне»):
используется Darken,
при необходимости отдельные области дополняются дубликатом в Normal с маской.

Практика: Screen для светящихся эффектов

Screen применяют для переноса на картинку светящихся светлых объектов на чёрном фоне:
дым,
пламя,
молнии,
засветки и другие световые эффекты.
Чёрный в Screen нейтрален, поэтому «чёрный фон» становится прозрачным.
Светящимся объектам в Screen нельзя снижать непрозрачность: визуально это выглядит «не по жизни». Нужен контроль яркости, а не прозрачности.
Над световым слоем создаётся корректирующий слой Curves.
Коррекция ограничивается clipping mask (чтобы влияла только на световой слой).
Для огня точку белого не опускают: хотя бы по одному каналу белый должен оставаться максимально ярким, иначе огонь «перестанет быть огнём».

Практика: Multiply как «печать принтера»

Multiply работает как печать на принтере или рисование акварелью по бумаге:
белая бумага «подкладывает» свой цвет,
белые участки изображения краской не печатаются,
на цветной «бумаге» белое становится цветом бумаги, и цвета в целом «подплывают».

Пример

«Напечатать» логотип/принт на ткани:
поместить подготовленный логотип на фотографию,
трансформировать по форме,
перевести логотип в Multiply.

Проблема цвета основы

На жёлтой футболке или цветной поверхности цвета принта смешиваются с цветом основы.
Показаны варианты решения:
дублировать логотип и использовать режим Color, чтобы сохранить цвета логотипа,
либо подготовить подложку: сделать участок «как белая офисная бумага».

«Белая офисная бумага»

загрузить выделение по логотипу,
создать слой Hue/Saturation ниже логотипа по выделению и обесцветить основу,
создать Curves и осветлить основу,
сделать Curves клиппинг‑маской к Hue/Saturation.

Контроль отсечки в Curves

При движении точки белого в Curves используется Alt для режима отсечки:
при зажатом Alt видно, где начинается клиппинг,
точку белого двигают до начала отсечки и немного возвращают назад.

Перенос зеркальных бликов на «глянцевый принт»

Напечатанный принт часто бликует как глянец. Зеркальные (спекулярные) блики переносятся отдельным слоем.
Загрузить выделение по маске области принта.
Сделать копию «того, что видно на экране» в эту область (Shift+Ctrl/Command+C).
Вставить на новый слой над принтом.
Перевести слой в Screen.
Если блики «неправильные» из‑за слишком светлой базы — затемнить этот слой Curves в клиппинг‑маске так, чтобы получилась почти чёрная картинка только с белыми бликами.

Практика: перенос теней на новый фон через Multiply

Пересадить светлый объект на новый фон и сохранить естественные контактные тени.
Дублировать слой с исходником (или нужную часть сцены).
На исходном слое выделить объект с помощью Select Subject и создать маску, так чтобы объект отделился от исходного фона, временно скрываем слой.
Перевести копию слоя (где проявляем тени) в Multiply.
Маской и/или градиентом ограничить, где тени должны проявляться.
Curves‑коррекцией сделать «пол» максимально белым (белый для Multiply нейтрален), чтобы на слое остались в основном тени.
Чёрной кистью убирать лишние затемнения

Практика: замены/добавления неба (облаков)

Ч/б картинка из красного канала

В красном канале белые облака темном небе:
Открыть панель Channels.
Скопировать канал.
Поместить в нужную картинку на слои в Screen и усилить контраст при необходимости (Curves) в clipping mask к этому слою

Вариант переноса через Overlay / Soft Light

слой с небом/фактурой переводится в Overlay или Soft Light (результат действия которого нравится больше);
уменьшаем насыщенность слоя через Hue/Saturation в clipping mask чтобы убрать перенасыщенность цветов при наложении.

Вариант через Multiply

Multiply используют, когда небо/облака должны затемнять основу и при этом «пропускать» светлые области (белое в Multiply нейтрально).
Базовая схема:
Положить слой с небом над изображением (в котором важный объект вырезается маской от воздействия)
Перевести слой в Multiply.
Корректирующим слоем Curves сделать так, чтобы «небо-фон» стало максимально светлым/белым, а на слое остались в основном облака/тональные перепады.
Коррекция переводится в Luminosity когда нужно взять из коррекции только яркостную составляющую и не менять цвет.

Практика: прозрачные объекты (стекло) и Hard Light

Особенности задачи

Для бутылок/стекла важны одновременно света и тени, а также «плотность» стекла. Логика съёмки:
нейтральный ровный фон,
равномерный свет,
фон привести к среднему серому 128, потому что для контрастных режимов это нейтраль.

Почему Hard Light

Hard Light объединяет Screen и Multiply вокруг среднего серого, поэтому может переносить и светлую, и тёмную составляющую прозрачного объекта.

Сделать натюрморт «более картинным» (текстура стены)

Заменить простой серый студийный фон на более живописную «текстурную стеночку» и собрать итог так, чтобы всё выглядело естественно.

Подбор режима наложения для текстуры

Для накладывания стены на средне‑серый фон подходят:
Overlay (часто лучший),
Soft Light,
Hard Light.
Не подходят по смыслу:
Screen (не световой эффект и не чёрный фон),
режимы осветляющей/затемняющей группы, если фон и текстура оба «средние» по яркости,
Color (перенесёт цвет, но не фактуру),
Vivid Light / Linear Light (дают агрессивную отсечку).

Обработка стелка (бокала) отдельно от остального изображения

Сделать дубль слоя стены.
Выделить только прозрачную часть стекла (без поверхности вина).
Этим выделением ограничить дубль стены.
Вынести слой из группы, если группа «не даёт видимости».
Перевести дубль стены на бокал в Soft Light (даёт ощущение «плотности» стекла).
Для правки маски: маленькая чёрная кисть средней жёсткости.
Для ровного края: рисование по точкам с зажатым Shift.

Режимы наложения, которые почти не используются

Режимы Vivid Light, Linear Light, Color Dodge, Linear Dodge, Color Burn, Linear Burn в реальной практике для «вживления» используются крайне редко, потому что они агрессивно двигают края тонового диапазона и уводят их в отсечку.
Исключение из «почти никогда»: Linear Light нужен в частотном разложении.
Pin Light и Hard Mix обозначены как режимы, к которым обычно не обращаются.
