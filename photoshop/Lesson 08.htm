Маски слоя и выделения: базовая теория

Что такое маска слоя

Маска слоя прикрепляется к слою кнопкой Add Layer Mask.
Маска — это «карта видимости» слоя:
белое на маске — слой виден;
чёрное на маске — слой не виден;
серое — слой виден частично (полупрозрачность), чем темнее серый, тем меньше видно.
Важно различать, что активно:
если рамка выделяет слой, изменения идут по слою;
если рамка выделяет маску, изменения идут по маске.

Быстрые действия с маской

Alt‑клик по маске — просмотр содержимого маски.
Shift‑клик по маске — временно отключить/включить маску (появляется крестик).
Связь слоя и маски:
значок «цепочки» между слоем и маской связывает их движение;
если «цепочку» отключить, можно двигать слой отдельно или маску отдельно.

Удаление и применение маски

Надёжные способы удалить маску без сюрпризов:
перетащить маску на «корзину»;
контекстное меню по маске → Delete Layer Mask.
Apply Layer Mask применяет непрозрачности маски к слою, после чего маску нельзя редактировать как маску.

Маска из выделения

Command/Control‑клик по миниатюре слоя загружает выделение по непрозрачным пикселям слоя.
Если при создании маски есть активное выделение, маска создаётся по текущему выделению:
там, где «бежит пунктир», маска становится белой;
остальное становится чёрным.
Если выделения нет, создаётся белая маска.

Свойства маски: Density и Feather

Density уменьшает «силу» маски: при 0 маска становится по сути белой.
Feather размывает маску и создаёт серые градации на границе (степень проявленности слоя - чем белее, тем непрозрачней слой с маской).

Инверсия маски

Command/Control + i - инверсия маски превращает белое в чёрное и наоборот (маска была белая → стала чёрная).

Группы и маски

Слои можно складывать в группу (Command/Control + G).
У каждого слоя может быть своя маска, и у группы тоже может быть своя маска.

Изменение размера выделения

Команды Select → Modify → Contract/Expand уменьшают или увеличивают выделение на заданное количество пикселей.

Color Range

Select → Color Range создаёт выделение по цвету без чётких границ.
Инструменты внутри Color Range:
пипетка — выбрать цвет;
пипетка с «плюсом» — добавить цвета;
пипетка с «минусом» — убрать цвета;
Fuzziness — строгость отбора: больше значение → выделение «шире» по похожим цветам

Логика обработки

Выделить нужную область пикселей → дать ей одну коррекцию; выделить другую область → дать другую коррекцию.
Маски + кривые + Hue/Saturation позволяют сделать большую часть обработки; для следующего шага нужны режимы наложения.

Комбинирование масок, копирование и сохранение, Quick Mask

Комбинирование масок

«Сложение/вычитание/пересечение» масок на практике реализуется логикой слоёв:
одна маска может быть на группе, другая — на слое внутри;
дополнительная чёрная маска с прорисовкой белой кистью даёт «пересечение» с маской группы.
Пример логики «пересечения»:
группа ограничивает влияние по персонажу;
внутри группы на отдельном корректирующем слое маска чёрная, и белой кистью проявляется только кожа;
штрихи, выходящие за границы персонажа, отсеиваются маской группы.

Копирование элементов маски

Можно скопировать маску целиком или её часть:
перейти в просмотр маски → выделить всё → скопировать;
вставить как отдельный слой;
затем вставить обратно в другую маску.
Практичный подход: сделать «болваночный» слой, создать на нём нужный элемент маски, отключить слой и использовать его как заготовку для вставки.

Выделение по маске

Command/Control‑клик по миниатюре маски загружает выделение, которое могло бы создать такую маску.
Дальше выделение можно:
инвертировать (Shift + Command/Control + I);
заливать на другой маске белым/чёрным, комбинируя области.

Quick Mask

Режим Quick Mask включается/выключается клавишей Backslash ().
Если «всё стало красным», причина часто в случайном включении Quick Mask; выключение возвращает обычный режим.

Object Selection Tool и Select Subject: выделение объектов в практике

Object Selection Tool

Инструмент выделяет объекты «по смыслу» и может работать очень точно по рукам, голове и другим частям.
Режимы выделения:
прямоугольником (Rectangle);
лассо (Lasso) — полезно для диагональных и сложных элементов.
В настройках важны:
Sample All Layers — искать объекты по всей «схлопнутой» картинке, а не только по текущему слою;
Hard Edges — характер границы выделения.

Select Subject

Select Subject выделяет главный объект на фотографии.
Выделение можно дорабатывать:
Shift — добавление к выделению;
Alt/Option — вычитание из выделения;
при необходимости — обычным Lasso.

Организация коррекций по маскам

Послойная организация коррекций

Типовой шаг: создать корректирующий слой по выделению (выделение становится маской).
Если нужно много коррекций на одну область:
слой кладётся в группу;
маска перетаскивается на группу;
внутрь группы добавляются остальные корректирующие слои.

Воздействие на часть выделения маски

Если слой лежит внутри группы, на которой маска «пропускает» коррекцию на весь фон, коррекция будет действовать на весь фон.
Чтобы ограничить действие только на нижнюю часть фона:
использовать уже существующий слой, который влияет только на низ;
поставить новый корректирующий слой клиппинг‑маской к нижележащему слою (Alt + Ctrl/Command + G)

Перенос и дублирование масок

Маску можно:
перетащить на другой слой (перемещение);
перетащить с зажатым Alt/Option (дублирование).
Если маски должны быть строго одинаковыми, предпочтительнее:
клиппинг‑маска (одна общая маска на нижнем слое), либо
группа в группе с одной общей маской,
чтобы не редактировать две одинаковые маски вручную.

Сохранение маски «на будущее»

Вариант 1: хранить маски как слои в отдельной технической группе (выключить глазик).
Вариант 2: загрузить выделение по маске (Command/Control‑клик) и выполнить Select — Save Selection, сохранив выделение как канал. И при необходимости потом загрузить через через Cmd/Ctrl+клик.

Логика сложения и вычитания выделений по миниатюрам

Command/Control‑клик по миниатюре загружает выделение.
Добавление/вычитание выделения задают дополнительные модификаторы:
+ Shift добавляет;
+ Alt/Option вычитает.

Select Subject: обработка на устройстве или в облаке

В настройках Select Subject может быть выбор, где выполняется выделение:
на компьютере (используются ресурсы устройства, модель соответствует версии программы);
в облаке (может быть доступ к более новой модели, зависит от скорости интернета).

Практические кейсы обработки

Отдельная коррекция для героя и для фона

Для героя:
загрузка выделения героя;
корректирующий слой Curves по выделению;
слой складывается в группу, маска переносится на группу.
Для рук:
руки выделяются через Select Object с добавлением/вычитанием (включая исключение часов);
создаётся маска, инвертируется (Ctrl/Command + I);
затем на маске выполняется отдельная коррекция (в данном случае деструктивными кривыми через Cmd/Ctrl+M), чтобы руки осветлялись слабее.
Для фона:
активация выделения по герою (Cmd+клик по маске)
инверсия выделения (Shift + Command/Control + I);
отдельная группа фона с маской;
градиентом из чёрного в прозрачный ограничивается, где коррекция действует.

Важное правило про «вклеенность» объектов

При коррекции по маскам важно не допускать, чтобы объект выглядел «вклеенным».
Ключевая проверка: объекты, отражающие свет, не могут быть ярче источника света.
В пасмурный день источник света — небо, и объект не должен становиться светлее неба.
Исключение возможно при особых погодных условиях (например, когда солнце освещает объект сзади фотографа, а в кадре тёмные тучи), но это отдельный сценарий.

Рекомпозиция: удаление объекта с фона

Объект дублируется на отдельный слой и маскируется.
Выделение загружается по маске, слой с объектом временно отключается.
Выделение расширяется (пример: на 50 px для хайреза), чтобы точно захватить волосы и мелкие элементы.
Командой удаления Remove объект стирается с фона.
Созданная заплатка на новом слое
Временно отключенный слой можно двигать и масштабировать.

Рекомпозиция через маски и подрисовку

Маска персонажа переносится на группу.
Для проблемных мест по краю волос применяется быстрый ремонт
создание нового слоя, взятие пипеткой цвета тёмных волос и подрисовка мягкой кистью по краю (цветом), которая затем «пропускается» через маску.

Создание глубины: локальное осветление/затемнение фона

Делается разделение: передний план светлее, глубина темнее.
Используется вложенная структура групп:
группу фона, где уже отделена девочка,
группа с маской конкретного объекта фона,
внутри — Curves и дополнительная пустая маска, чтобы осветление проявлялось только в нужном углу.
Параллельно создаётся группа «всё кроме стены», внутри которой затемняются разные участки фона кистью и градиентом.

Практические советы по выделению

Если объект граничит с краем кадра, при выделении не тянуть Object Selection Tool от самой границы — оставлять небольшой «зазор», чтобы выделение работало стабильнее.
Если Select Subject выделяет плохо:
временно осветлить картинку и попробовать Select Subject ещё раз;
дальше дочищать Select Object + Lasso.

Локальные правки по деталям

Если небольшой участок «вылетает» по яркости (например, угол дивана):
корректирующий слой затемнения в клиппинг‑маске;
градиентом ограничить влияние (например, только на левую часть).

Доводка масок по краям (волосы и щетина)

Если фоновая коррекция «задевает» край волос не так, как нужно:
мягкой белой кистью аккуратно пропустить фоновую коррекцию по краюшку волос, работая краем кисти.
Для щетины используется полупрозрачная кисть (пример: 50% непрозрачности), чтобы переход был мягким.
