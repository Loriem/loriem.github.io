Слои, базовые операции и Clipping Mask

Типы слоёв

Слои бывают пиксельные (растровые) и «все остальные» (например, текстовые и корректирующие).
При открытии фотографии в документе обычно один слой (фон/Background) в палитре Layers.

Создание нового пустого пиксельного слоя

Команда: Ctrl/Command + Shift + N (New).
В диалоге можно задать:
имя слоя;
цветовую метку слоя (для удобства поиска в структуре);
режим наложения и непрозрачность.
Прозрачность нового слоя показывается «шашечками» на миниатюре.

Порядок слоёв

Логика «слоёного пирога»: слой выше перекрывает слои ниже.
Порядок меняется перетаскиванием слоя мышью вверх/вниз в палитре Layers.

Выбор слоя и навигация по слоям

Выбор слоя: клик по нужному слою в Layers.
Перемещение активного слоя по структуре доступно через меню Layer, но в занятии подчёркнут приоритет мыши и шорткатов.
Команды, которые пригодятся дальше (в том числе для экшенов):
Alt + [ / ] — переход вверх/вниз по слоям.
Shift + Alt + [ / ] — выделение диапазона слоёв.
Ctrl/Command + [ / ] — перемещение слоя выше/ниже.
Ctl+клик мышьюпо слою/слоям в Layers — выделение слоя/слоев
Shift+клик мышьюпо слою в Layers — выделение диапазона слоёв от текущего до того, по которому кликнули.

Быстрый доступ к Move Tool

При зажатом Ctrl/Command текущий инструмент временно превращается в Move Tool.
Для Move Tool должна быть отключена галка Auto Select.
Move Tool обычно не выбирается вручную из панели — используется «из-под руки».

Как двигается содержимое слоя

Если выделения нет — двигается весь активный слой.
Если есть выделение (бегущий пунктир) — двигается только выделенная область на активном слое.

Видимость, переименование, непрозрачность

«Глазик» включает/выключает слой.
Переименование слоя: двойной клик по названию.
Opacity меняет непрозрачность выделенного слоя.
Fill тоже связан с непрозрачностью, но отличается в некоторых случаях; в практике занятия почти всегда используется Opacity.

Копирование и вставка

Ctrl + A — выделить всё.
Ctrl + C — копирует содержимое активного слоя (по факту — только непустые пиксели слоя).
Ctrl + V — вставляет содержимое буфера на новый слой (над выбранным на момент вставки), объект появляется по центру документа.

Дубликат слоя без смещения

Ctrl + J — дублировать активный слой целиком с сохранением расположения.
Если есть выделение — Ctrl + J дублирует только выделенную часть на новый слой.

Вырезать на новый слой

Shift + Ctrl + J — вырезает выделенную область на новый слой (на старом слое эта область исчезает).

Удаление

Удалить слой целиком: выделить слой и нажать Delete.
Стереть содержимое, но оставить слой:
сделать выделение;
нажать Delete — удаляется только выделенное.

Слияние и «скриншот на новый слой»

Ctrl + E — слить активный слой с нижележащим.
Если выделить несколько слоёв — Ctrl + E сольёт выделенные слои в один.
Не принято сливать слои, которые не идут подряд, чтобы не ломать логику расположения объектов.
Flatten Image — сливает все слои в один.
Alt + Shift + Ctrl + E — «слепить» всё видимое на новый слой (как снимок текущей видимости). Если команда не срабатывает из-за сложной структуры, создаётся новый пустой слой и команда применяется на нём.

Группы слоёв

Группировка нужна для удобства: логически связанные слои складываются в «папку».
Можно отключать видимость всей группы.
Команда: Ctrl/Command + G.
Разгруппировка используется редко.

Текстовые слои

Текст — отдельный тип слоя; в Layers он помечается значком T.

Clipping Mask

Применение: верхний слой (обслуживающий) показывается только в пределах нижнего (хозяйского/главного).
Команды:
контекстное меню: Create Clipping Mask;
шорткат: Alt + Ctrl + G.
В клиппинг-маску можно прикреплять и «обычные» слои, и корректирующие слои.

Как откреплять слои из клиппинга

Повтор Alt + Ctrl/Command + G на слое снимает клиппинг.
Если откреплять слой внутри цепочки, могут открепиться сразу все слои клиппинг-маски, потому что становится непонятно, к чему крепить оставшиеся.

Быстрый просмотр одного слоя

Alt-клик по «глазику» слоя показывает только этот слой (остальные скрываются).
Для слоёв в клиппинг-маске могут оставаться включёнными несколько глазиков из-за зависимости от хозяйского слоя.

Разлочить фон (Background)

Залоченный фон нельзя двигать и стирать «до прозрачности».
Разлочивание:
дважды клик по фону (не по названию),
OK.
После разлочивания фон становится обычным слоем: можно двигать, стирать ластиком до прозрачности.

Недеструктивная обработка, Channel Mixer и Hue/Saturation

Корректирующие слои и недеструктивность

Корректирующие слои создаются через иконку «половинка чёрного/белого круга» внизу панели слоёв.
Настройки активного корректирующего слоя показываются в палитре Properties.
Деструктивно: коррекция применяется прямо к пикселям (пример — кривые через Ctrl/Command + M). После подтверждения изменения «вшиваются» в пиксели, и дальше остаётся только история действий.
Недеструктивно: коррекция сделана корректирующим слоем — её можно в любой момент выключить, удалить или изменить.

Набор корректирующих слоёв, на которые делается упор

Curves — основной.
Hue/Saturation — основной для цвета.
Channel Mixer — реже.
Solid Color — служебный слой заливки.

Solid Color

Слой полностью залит одним цветом как «описание заливки», а не как «пиксельный растр».
По Solid Color нельзя рисовать кистью/ластиком как по обычному пиксельному слою.

Channel Mixer

В RGB цвет складывается из «мощностей» трёх каналов (красный/зелёный/синий) — как «лампочки», которые могут гореть сильнее/слабее.
При высокой насыщенности объекта перекраска кривыми может давать плохой результат.
Channel Mixer нужен, когда требуется сильно перебросить информацию из одного канала в другой, вплоть до перестановки каналов местами.
Для выбранного канала задаётся «рецептура» (проценты R/G/B), из которых он будет состоять.

Приёмы из демонстрации Channel Mixer

Перестановка каналов местами (например, положить 100% синего в красный и 100% красного в синий) меняет светлотность каналов и даёт противоположное изменение цвета.
Возможна смесь (условно 30–40–30) — Channel Mixer пересмешивает ч/б «картинки каналов» в заданной пропорции.
Полезная команда из практики: Shift + Ctrl + C копирует «всё, что видно на экране» (copy merged), а не только активный слой.

Монохром в Channel Mixer

Режим Monochrome позволяет выводить выбранный канал (или смесь каналов) в ч/б виде.
В курсе это нужно для получения ч/б канала недеструктивно и дальнейшего применения через режим наложения ради эффекта.

Hue/Saturation

Hue/Saturation живёт в логике HSB:
Hue — оттенок,
Saturation — насыщенность,
Brightness/Lightness — яркость.
Концептуально логика «человеческая», но внутри идёт пересчёт в RGB.

Ползунки и взаимосвязи

Hue меняет оттенок.
Saturation меняет насыщенность.
Lightness меняет яркость.
Lightness для выбранного цвета вмешивает белый/чёрный и тем самым понижает насыщенность.
Saturation тоже может менять яркость, поэтому при правке одного параметра часто приходится корректировать соседний.

Работа по отдельным цветам и диапазон влияния

Инструмент обычно применяется прицельно по выбранным цветам (красные/жёлтые/синие и т.д.), а не «на всю картинку».
На шкале видно, какой участок оттенков выбран.
Диапазон можно сдвигать и сужать:
внутренние «лепестки» — зона, где коррекция действует в полную силу;
между внутренними и внешними — зона плавного схода коррекции на нет.

Ограничение по сильной перекраске

Большой сдвиг Hue (например, ±180) даёт неконтролируемые разноцветные области на границах диапазона.
Hue/Saturation используется для небольших изменений оттенка (в пределах соседних оттенков, порядка 20–30 пунктов).
Перекраску «через всю радугу» удобнее делать Channel Mixer, а Hue/Saturation — для тонкой доводки.

Связка Channel Mixer + Hue/Saturation

Channel Mixer делает «большой перелёт» в другую часть спектра.
Hue/Saturation делает «тонкую доводку» оттенка/насыщенности/яркости уже в пределах близких значений.

Практика: компенсация после контраста

Поднятие контраста мастер-кривой может дать чрезмерную насыщенность и неприятный скинтон.
Вместо поканального поднятия контраста применяется подход:
поднять контраст мастер-кривой;
сверху Hue/Saturation компенсировать оттенки кожи.
Для точной настройки диапазона применяется «рентген»: временно ставится сильный сдвиг Hue (например, +180), чтобы увидеть, что цепляется диапазоном; затем возвращаются нормальные значения и делается аккуратная правка.
Нюанс про красные: разнос насыщенности через Saturation может выбеливать красный; если нужно убрать насыщенность, сохранив густоту тона, используется комбинация с Lightness.

Тонирование, Blend If, Color & Vibrance

Баланс белого и художественная логика

Баланс белого может быть холодным или тёплым.
Не всегда нужно приводить баланс белого к «правильному»: паразитный тёплый/холодный баланс белого может быть художественным ходом.
В примере: вместо поканальной постановки баланса белого делается экспонирование и корректировка оттенков жёлтых через Hue/Saturation.

Тонирование через Colorize

В Hue/Saturation есть режим Colorize: изображение тонируется в один цвет (с выбором оттенка и насыщенности).

Подмешивание синего в тени через Blend If

Задача: добавить синеву именно в тени.
Последовательность:
создать слой Hue/Saturation и включить Colorize (выбрать синий оттенок);
открыть Layer Style (двойной клик по области слоя справа от названия);
использовать Blend If:
Current Layer — текущий слой-тонировщик;
Underlying Layer — нижележащая картинка;
ограничить проявление тонировки по яркости нижележащего изображения (от чёрного до тёмно-серого);
расщепить границу ползунка с зажатым Alt, чтобы сделать переход мягким;
настроить Opacity слоя-тонировщика.

Пример точечных правок Hue/Saturation по коже и фону

Слишком ядреный синий:
взять синий пипеткой;
пипеткой с плюсиком расширить диапазон;
снизить насыщенность и подобрать Hue/Lightness так, чтобы цвет не бил по глазам.
Коррекция в более циановый только по коже (исключая фон):
переключиться на циановый
временно поставить Hue на +180, чтобы увидеть «что цепляется»;
сузить/сдвинуть диапазон лепестками так, чтобы влияние было на коже, а не на фоне;
вернуть Hue обратно и выполнить аккуратную коррекцию.
Исправление «рвущегося» цвета: если часть уже ушла из синего в мадженту, диапазон влияния (маджента) сдвигается, чтобы выровнять насыщенность.
Убор жёлтой тени (например, под носом): уйти в жёлтые, временно +180 для проверки диапазона, затем сделать оттенок более красноватым, светлее и менее насыщенным.

«Выжать жёлтый» и роль порядка слоёв

Усиление жёлтого достигается снижением синего через Curves.
При насыщенном фоне кожа может визуально казаться «мертвой», поэтому принято подмешивать цвета фона в кожу.
Hue/Saturation можно положить под слоем Curves, который «пожелтит» картинку:
снизу останется различие между жёлтым и красновато-оранжевым;
по этому различию Hue/Saturation цепляется за кожу и сдвигает её в более оранжевую сторону.

Color & Vibrance

Корректирующий слой объединяет четыре ползунка:
Temperature и Tint (баланс белого как ползунки),
Vibrance и Saturation.
Use Legacy включает старый математический алгоритм.
Разница Vibrance и Saturation:
Saturation действует линейно по всем пикселям;
Vibrance сильнее влияет на мало насыщенные пиксели и слабее — на сильно насыщенные.
Практический смысл: аккуратно поднять насыщенность, «донесытив» малонасыщенные объекты, и комбинацией Vibrance/Saturation выровнять насыщенность элементов с одинаковым оттенком.

Порядок корректирующих слоёв

Каждый последующий корректирующий слой получает всю нижележащую картинку.
Просчёт слоёв идёт снизу вверх.
Перестановка двух корректирующих слоёв местами меняет результат, потому что меняется, какая версия изображения «скармливается» следующему слою.

Тонирование

Тонирование — изменение оттенков с целью эстетической гармонизации.
Примерная логика результата:
база: low-contrast — поднять точку чёрного с фиксацией средних тонов, чтобы тени стали мягче и менее «мусорными»;
охладить тени: поднять точку чёрного в синем канале, немного в зелёном, и убрать красный в тенях (при фиксированной правой части диапазона);
слегка потеплить света: опустить точку белого в синем канале, при необходимости чуть компенсировать зелёным, чтобы света не стали «лимонными»;
поднять общую насыщенность;
отдельно приглушить синюю одежду через Hue/Saturation
Отдельный вывод по порядку: слой, который убирает синюю насыщенность одежды, располагается ниже слоёв, которые усиняют тени, чтобы одежда корректировалась до общего усинения.
