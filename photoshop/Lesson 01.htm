Базовые настройки Photoshop

Preferences / Settings

Как открыть настройки:
Windows: Edit → Preferences → (нужный раздел).
macOS: Photoshop → Settings/Preferences → (нужный раздел).
Быстрый вызов окна настроек: Command/Control + K.
Photoshop может быть на английском или на русском — команды и кнопки находятся в одном и том же месте.
Настройка делается «один раз на всю жизнь».

General

Снять галку Auto Show Home Screen (убирает приветственное/рекламное окно с недавними документами; может быть баг и появляться даже при снятой галке).
Поставить галку Use Legacy New Document Interface (старый дизайн окна создания нового документа; принципиально ничего не меняет).
Поставить галку Use Legacy Free Transform (старая логика свободной трансформации; при новой логике Adobe меняется поведение горячих клавиш).

Notifications

Включить Enable Quiet Mode (тихий режим).
Если тихий режим включен, при наведении на инструменты/кнопки не всплывают подсказки с объяснениями и мини-видео.

Cursors

Включить Show Crosshair in Brush Tip (точечка в центре кружка курсора кисти).

Performance

Можно дать Photoshop больше памяти, если её много.
Больше 70–80% лучше не давать, иначе может тормозить операционная система.

Scratch Discs

Scratch Discs — «логические диски», которыми Photoshop может пользоваться для временных файлов во время работы (буфер, временные данные).
Можно разрешить несколько дисков (например, C/D/E/F), чтобы при нехватке места Photoshop мог использовать дополнительные.

Организация рабочего пространства и панелей

Базовый принцип

Любую панель можно схватить и перетащить, закрепив в другое место.
Дефолтовый набор панелей «абсолютно бесполезен» — лишнее закрывается.

Что закрывается

Color — не нужен (вытаскивается и закрывается).
Libraries — не нужно.
Adjustments — не нужно.
Остальные закрытые панели можно вернуть через меню Window.

Что нужно включить и где разместить

Navigator (Window → Navigator) — в верхнюю панель.
В правой нижней части: Layers, Channels, Paths (Paths, вероятно, не нужен, но можно оставить).
Properties — переносится в правую часть, чтобы видеть настройки корректирующих слоев.
History (Window → History) — «машина времени» для отката действий.
Actions (экшены) — понадобится позже.
Brush Settings — понадобится (Photoshop часто предлагает сразу две панели: Brushes и Brush Settings; нужна именно Brush Settings).
Дополнительно (не обязательно): Histogram.

Показ профиля документа в интерфейсе

В левом нижнем углу Photoshop есть стрелочка (переключатель информации рядом с масштабом).
В выпадающем списке выбрать Document Profile.
Тогда рядом с масштабом будет отображаться профиль документа.

Настройки цвета (Color Settings)

Меню Edit → Color Settings.
В пункте для Gray выбрать S Gray.
Это нужно, чтобы в каналах ч/б отображение совпадало с тем цветотоном, который используется в слоях.

Форматы файлов: для работы и для демонстрации

Две группы форматов

Форматы для редактирования и хранения (профессиональная работа).
Форматы для демонстрации (в основном интернет).

Форматы для редактирования и хранения

PSD (Photoshop Document) — нативный формат, хранит слои, прозрачность, ничего не портит, без искажений.
PSB (Large Document Format) — нативный формат, только используется, если файл больше 4 ГБ и PSD не подходит.
TIFF — универсальный большой бескомпрессионный формат, может хранить слои; часто используется как однослойный документ для типографии, но слои тоже поддерживает.

Форматы для демонстрации

JPEG — основной формат для интернета; слои не хранит, прозрачность не умеет; есть искажения (картинка «будет портиться», но контролируемо), зато файл маленький и быстро грузится.
PNG — чаще для «сайтостроения»: логотипы, иконки; слои не хранит, но умеет прозрачность; пиксели не искажает как JPEG, обычно весит больше JPEG.

Горячие клавиши

Горячие клавиши важны для скорости работы и для экшенов.
Сокращения видны рядом с пунктами меню, а у инструментов — в подсказке при долгом удержании мыши.

Как читаются клавиши

Command (⌘) (Mac) = Control (Windows).
Стрелочка вверх = Shift (⇧).
Значок «недоделанный x» = Alt (⌥).

Операции с файлами

Создать новый файл

File → New
Горячая клавиша: Command/Control + N.
Важны ширина и высота в пикселях.
Если в буфере обмена есть графика, при создании нового файла метрика буфера подставляется автоматически.
Можно выбирать стандартные размеры (например, A4).

Открыть файл

File → Open
Горячая клавиша: Command/Control + O.
Альтернатива: перетащить файл на иконку программы (Mac) или в окно программы (Windows).

Сохранение: Save, Save As, Save a Copy

Save (Command/Control + S) сохраняет текущий документ, если он уже был сохранен раньше.
Save As сохраняет документ «как» и переводит работу на новый файл.
Save a Copy сохраняет копию, но оставляет работу в текущем документе.
Это стало «путано», потому что раньше фактически было проще и без отдельной команды Save a Copy.

TIFF и компрессия

При сохранении в TIFF появляется окно с параметрами сжатия.
Совет для TIFF: включать LZW compression (без потери качества, но файл весит меньше; сохранение/открытие могут быть чуть дольше).
Если в TIFF сохраняются слои, будет галочка Layers: включена — слои сохраняются, выключена — слои схлопываются.

Сохранение JPEG: качество 10–12 и правило «не пересохранять JPEG из JPEG»

При сохранении в JPEG важный параметр — Quality (качество).
Quality 12:
дает самый большой размер файла;
используется, когда в картинке есть очень плавные градиенты (например, размытой студийный фон), чтобы избежать заметной постеризации/«лестницы».
Если очень плавных градиентов нет, обычно достаточно качества 10: визуально нормально, вес файла меньше.
Когда плавные градиенты есть, качество можно повышать до 11–12, чтобы градиенты «не поплыли».
Важное правило:
не открывать JPEG, править и снова сохранять в JPEG много раз;
правильно: хранить послойник и каждый раз выгружать JPEG из послойника.
Причина: JPEG использует сжатие, и при повторных пересохранениях качество постепенно ухудшается, особенно на контрастных переходах.

Duplicate

Команда Image → Duplicate создает дубль документа со всей послойной структурой и открывает его рядом.

Закрытие

File → Close
Горячая клавиша: Command/Control + W.
Если документ не сохранен, появится диалог: сохранить Save / не сохранять Don't Save / отменить закрытие Cancel.
Для большого количества файлов есть команда Close All (Photoshop спросит по каждому файлу; есть галочка «Apply to all»).

Изменение размера изображения

Команда

Image → Image Size
Горячая клавиша: Alt + Command/Control + I.

Единицы измерения

В большинстве задач используется измерение в пикселях.

Resolution

Цифра Resolution — «фикция».
Важно только количество пикселей по ширине и по высоте.
Resolution — команда для принтера: с какой плотностью распечатывать пиксели.

Пропорции

Иконка «звенья цепи» включает пропорциональное изменение ширины/высоты.
Если цепочка выключена, ширина и высота могут меняться диспропорционально (картинку «сжимает и разжимает»).

Resample и алгоритмы

По дефолту стоит автоматический выбор.
«Честное математическое» уменьшение/увеличение связывается с Bicubic.
Автоматический режим может выбирать варианты с «улучшайзерами»:
Bicubic Sharper (reduction) — уменьшение с добавлением резкости.
При увеличении — вариант с «додумывалкой», чтобы стало чуть-чуть получше.

Зачем уменьшать

Частая задача — подготовка к публикации в соцсетях.
Если отправить в соцсеть полновесную большую картинку (high res), соцсеть уменьшит сама и плавные градиенты могут превратиться в «лесенку».
Лучше уменьшать самостоятельно до размера, который понимает соцсеть.

Пример для Instagram

Вертикальный пост: 1080 × 1350 пикселей.
При правильном соотношении сторон (4:5) достаточно ввести ширину, высота подставится пропорционально.

Апскейл

Почему обычное увеличение через Image Size плохо

Увеличение через Image Size «не изобретет новых деталей».
Пример: уменьшить под Instagram, потом увеличить обратно — детализация становится «ужасной».

Generative Upscale

В меню Image есть команда Generative Upscale.
Выбор кратности увеличения (например, в 2 раза или в 4 раза).
Можно выбирать модель для увеличения.

Сторонние сервисы

В реальной практике для апскейла часто лучше пользоваться сторонними сервисами типа «Magnific.ai».

Изменение размера холста

Команда

Image → Canvas Size
Горячая клавиша: Alt + Command/Control + C.

Смысл

Canvas Size меняет размер холста, а не масштабирует сам объект.
Пример: добавить «рамочку» или поля для текста.

Настройки

Новая ширина и высота задаются в пикселях или процентах.
«Роза ветров» (якорь): со стороны стрелочек добавляется новое пространство.
Если точка смещена в левый верхний угол, новое пространство дольется справа и снизу.

Откат действий и History

History

Каждое действие отображается в History.
Можно откатываться к любому состоянию, пока оно хранится в истории.
Количество состояний: History States 50 (в настройках можно увеличить, но система начнет «задыхаться»).

Snapshot

Можно сделать Create new Snapshot (значок фотоаппарата).
Snapshot хранится независимо от того, сколько действий сделано потом, и к нему можно вернуться.

Фиксация состояния через левый столбик

В панели History можно зафиксировать конкретное состояние в списке истории.
Делается через левый столбик с пустыми окошками рядом со строками истории: поставить отметку у нужного состояния.
«Аналог снапшота»: даже если выполнить очень много действий после этого и превысить количество сохраняемых шагов History, отмеченная строка остается доступной для отката.
Практический смысл: держать под рукой «точку возврата», чтобы в любой момент откатиться к нужному состоянию.

Отмена действий

Ctrl + Z (настройки могут влиять на то, как именно работает многократный откат).

Каналы, битность, тоновые уровни

Каналы (Channels)

Изображение в режиме RGB состоит из трёх каналов: Red, Green, Blue.
В панели Channels есть общий канал RGB (композит) и отдельные каналы по каждому цвету.

Как выглядят каналы

Канал показывается как ч/б-карта.
Светлое в канале означает, что значение этого канала выше, тёмное — что ниже.
Переключение «глазиком» у каналов позволяет посмотреть вклад каждого канала в итоговую картинку.
По содержанию канал — это распределение значений, из которых складывается яркость и цвет, они переплетены и это создает проблемы при цветокоррекции. Пример:
RGB
Red
Blue
Ctrl/Cmd + клик по миниатюре канала — загрузить выделение по яркости (по содержимому канала).

Альфа-каналы

В Channels можно хранить выделения как отдельные ч/б-маски — Alpha channels (внизу списка каналов).

Где открыть панель Channels

Window → Channels (обычно панель размещают рядом с Layers).

Связь с настройкой Gray = S Gray

Настройка Gray = S Gray нужна, чтобы ч/б отображение и расчёт яркости в каналах/масках совпадали с тем цветотоном, который используется в слоях (и не давали «не тот оттенок серого» при проверке).

Тоновые уровни

Тоновые уровни — «оттенки серого, от чёрного до белого».
Нулевой тоновый уровень — чёрный.
Максимальный тоновый уровень — белый.

Confirm/Convert to Profile и приведение к sRGB

Базовая идея

В «интернете портится цвета», если профиль документа не тот.
В работе используется sRGB.

Откуда берутся другие профили

Картинка «неизвестного происхождения».
Фотоаппарат — если неправильно выставлены настройки.
Нейросеть — может отдать не sRGB или вообще «не тегнутый» профиль.
Телефон.
Скриншот.

Как действовать

Все приводится к sRGB.
Делать это лучше в начале работы с файлом, потому что операции с профилями могут «схлопывать слои».
Если другой профиль обнаружился в конце обработки:
послойник сохраняется с тем профилем, с которым он существует;
JPEG, который «слили из этого послойника», конвертируется к sRGB, и в интернет отправляется уже sRGB-файл.

Convert to Profile и Flatten Image

При Convert to Profile проверяйте активность параметра Flatten Image (схлопывание слоев) для сохранения внешнего вида изображения, иначе цветокоррекция на слоях при конвертации может отличаться.

8 и 16 битное изображение, постеризация

8 бит

В 8-битной картинке: 256 тоновых уровней.
Объяснение через «лампочки» в пикселе (красная, зелёная, синяя): каждая может гореть с 256 мощностями.
8 бит = 2 в 8 степени = 256.

16 бит

16 бит = 2 в 16 степени = 65536 вариантов.
16-битная картинка весит больше, потому что для каждого пикселя по каждому из трех каналов записывается число, «которое больше места занимает при записи».

Зачем нужен 16-битный режим

В большинстве случаев работа идет в 8 бит.
16 бит интересует «исключительно и только в одном случае» — чтобы избежать «лесенки» на плавных градиентах.

Постеризация

«Лесенка» на плавных градиентах называется постеризация.
Причина: слишком мало градаций (тоновых уровней) между соседними уровнями.
Ситуации, где встречается:
алгоритмы соцсетей (пример: Instagram уменьшает изображение и делает «лесенку» на градиентах);
разглаживание/размытие фона до идеального градиента (стены, бумажные фоны, неравномерный свет по фону).

Практический способ борьбы

Перейти в 16 бит: Image → Mode → 16 Bits/Channel.
Выполнить нужные изменения (пример: повторить гауссово размытие).
Добавить чуть-чуть шума.
Вернуться в 8 бит.
Сам переход 8 → 16 «не добавит новой информации» сам по себе.
Новые промежуточные тоновые уровни появляются в момент операций (например, размытия) в 16-битном режиме.
